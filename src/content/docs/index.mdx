## 🕌 Built for the Muslim Community

**Musafir** helps Muslim travelers worldwide by providing:

- **🍽️ Halal Restaurant Discovery** - Find verified halal food options
- **🕌 Mosque & Prayer Room Locator** - Locate nearby mosques and prayer facilities  
- **🗺️ Travel Planning** - Create custom itineraries combining food and prayer locations
- **⭐ Community Reviews** - Share and read reviews from fellow Muslim travelers

---

## 🛠️ Technology Stack

- **Frontend**: Flutter 3.16.x with Material Design 3
- **State Management**: GetX for reactive programming
- **Backend**: Firebase (Auth, Firestore, Analytics, Crashlytics)
- **Maps & Location**: Google Places API, Maps SDK, Geocoding API
- **Architecture**: Clean MVC with Repository pattern
- **Testing**: Unit, Widget, Integration, and E2E testing
- **CI/CD**: GitHub Actions for automated deployment
